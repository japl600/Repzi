# Settings screen (v1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a fourth bottom-bar tab, "Settings", with Language, Rest timer vibration, Licenses, Source code and Version rows.

**Architecture:** New module `:feature:settings` (MVVM, one UI state, stateless screen), a `SettingsRepository` interface in `core:domain` implemented with Preferences DataStore in `core:data`, and `SessionViewModel` reading the vibration preference when a rest countdown ends. The licenses list comes from AboutLibraries, applied in `:app`.

**Tech Stack:** Kotlin, Compose M3, Hilt, Preferences DataStore, AboutLibraries.

**Spec:** `docs/superpowers/specs/2026-11-18-settings-design.md`

## Global Constraints

- `core:domain` has no Android dependencies; the preference is an interface there, implemented in `core:data`.
- `minSdk` 26: the Language row (`Settings.ACTION_APP_LOCALE_SETTINGS`) is shown only on API 33+.
- Version name and code are read with `PackageManager` in the screen (not `BuildConfig`; `longVersionCode` needs API 28, so use `PackageInfoCompat.getLongVersionCode` and add `androidx-core` to the version catalog if it does not resolve).
- Rest timer vibration defaults to **on**; the decision is made in `SessionViewModel`, which sends `SessionEffect.RestFinished` only when it is on.
- No placeholder rows. Out of scope: weight units, data export, the wger attribution line (added with level 3).
- UI strings in English by default plus `values-es` in each module; code comments, README and commit messages in English.
- Follow the existing pattern: ViewModels inject use cases, screens are stateless composables (`XxxRoute` wires Hilt, `XxxScreen` takes state and callbacks), tests use fakes from `core:testing`.
- One commit per task, local commits are fine; **push only when the user asks**, one commit at a time. Commit messages end with the two attribution lines given in the session reminder.
- Windows: build with PowerShell, `.\gradlew.bat <task> | Out-String | Select-String 'BUILD (SUCCESSFUL|FAILED)|^e: |FAILED'`. `connectedDebugAndroidTest` needs the `Pixel_10` emulator and wipes the app's database.

## Review Focus

1. Language row on Android 8 to 12 (API below 33): hidden, no crash. (Task 1 test)
2. A phone with no app that handles the Language or Source code intent: the tap does nothing instead of crashing. (Task 1 test)
3. Vibration switched off while a countdown is already running: the end of that countdown does not buzz. (Task 2 test)
4. Fresh install: vibration is on, and the value survives creating a new repository on the same file. (Task 2 tests)
5. Corrupt or unreadable preferences file: vibration falls back to on instead of crashing the Settings or Session screen. (Task 2 test)
